# Estevam Personal

Site profissional de personal trainer, desenvolvido com **HTML**, **CSS** e **JavaScript** puros.

🔗 **Acesse o site:** [estevam-personal.vercel.app](https://estevam-personal.vercel.app)

---

## 📋 Sobre o projeto

Site profissional criado para divulgar meu trabalho como **personal trainer**. O objetivo é apresentar meus serviços, facilitar o contato com novos clientes e fortalecer minha presença online como profissional da área.

Através do site, é possível conhecer um pouco mais sobre minha abordagem de treino, os serviços oferecidos e como entrar em contato para agendar uma consultoria ou aula.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização e responsividade
- **JavaScript** — interatividade

## 📁 Estrutura do projeto

```
estevam-personal/
├── css/           # Arquivos de estilo
├── img/           # Imagens utilizadas no site
├── js/            # Scripts JavaScript
└── index.html     # Página principal
```

## ⚙️ Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/estevamwiu/estevam-personal.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd estevam-personal
   ```
3. Abra o arquivo `index.html` no navegador, ou use uma extensão como o **Live Server** (VS Code) para visualizar com recarregamento automático.
